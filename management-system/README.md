# Lab Assignment – 03  
HTML & CSS Fundamentals – Static Web Page Design

## Assignment Title
Designing a Static Student Management System Web Interface Using HTML and CSS

## Brief Description
This project is created as part of **Lab Assignment–03** for the course  
**Web Technologies and Platforms**.

The objective of this assignment is to design a **static management-based
web interface** using **HTML5 and CSS3**. The project focuses on proper
use of semantic HTML elements, external CSS styling, spacing, and layout
using normal document flow.

No backend functionality or JavaScript is included. Advanced CSS
techniques such as **Flexbox, Grid, Positioning, and Media Queries**
are strictly avoided as per assignment constraints.

## Technologies Used
- HTML5  
- CSS3 (Basic styling only)

## Pages Included
- Home Page (`index.html`)
- Login Page (`login.html`)
- Dashboard Page (`dashboard.html`)
- Data Listing Page (`list.html`)

All pages are linked together using HTML anchor tags for navigation.


## Steps to Run the Project
1. Clone or download the repository.
2. Open the project folder.
3. Open `index.html` in any modern web browser.
4. Navigate through the pages using the menu links.

## Notes
- This is a **static web interface only**.
- Layout is achieved using **block and inline-block elements**.
- The project follows all constraints mentioned in the assignment
  description.
