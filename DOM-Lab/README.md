# DOM Manipulation Lab

## Objective
This lab helps understand how JavaScript interacts with HTML using the Document Object Model (DOM).
By completing this lab, students learn how to:
- Select HTML elements using JavaScript
- Modify content dynamically
- Handle user events like button clicks
- Understand DOM structure and behavior

## Task 1: DOM Structure & Selection

### Elements Created:
- Heading (h1)
- Paragraph (p)
- Button
- Unordered list (ul with li items)

### JavaScript Methods Used:
- getElementById()
- getElementsByClassName()
- getElementsByTagName()
- querySelector()
- querySelectorAll()

### Output:
All selected elements are logged in the browser console.

---

## Task 2: DOM Content Manipulation

### Features Implemented:
- Updated heading using:
  - innerText
  - textContent
  - innerHTML
- Button click updates paragraph text
- Text is appended instead of replaced
- Paragraph length displayed dynamically
