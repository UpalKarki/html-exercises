# Web Development Lab – Week 3

## Assignment Title
Interactive Product Card and User Registration Form with Validation and UI Features

## Project Description
This project is developed as part of the **Week 3 Web Development Lab**.
The objective of this assignment is to build an interactive and user-friendly
web page using **HTML, CSS, and Vanilla JavaScript only**.

The project includes a product card component and a user registration form
with client-side validation, error handling, password visibility toggle,
and dark/light mode support.

No external libraries or frameworks are used.

## Technologies Used
- HTML5
- CSS3
- JavaScript (Vanilla JS)

## Features Implemented
- Product card with image, description, price, and add-to-cart button
- Success message when product is added to cart
- Fallback text when product image fails to load
- User registration form with validation
- Error messages shown below input fields
- Invalid inputs highlighted using CSS
- Password show/hide toggle for password fields
- Form submission prevention on validation failure
- Success message displayed on successful submission
- Dark mode and light mode toggle
- Theme persistence using localStorage

1. Clone or download the repository from GitHub.
